V0.5.1 목표:
  AutoCAD 2019에서 G 레이어의 문자·선·폴리라인을 읽고,
  우측 하단 '부품목록' 아래 제목과 그 위 구성품 셀을 탐색하여
  품목번호/품명/수량/부품번호/도면번호를 후보 CSV로 만듭니다.
  왼쪽 연장표도 동일 격자 조건이면 후보로 탐색합니다.
  이번 버전은 표 구조 진단·후보 추출 시험판입니다.
  조립 상하위 관계, XLSX 자동 생성, 블록 안의 문자/선,
  XREF 내부 객체, 곡선형 표경계는 아직 지원하지 않습니다.
  독립적인 TEXT/MTEXT 및 LINE/LWPOLYLINE 대상입니다.
  표 후보는 사람이 실제 부품표와 대조하기 전 확정 BOM이 아닙니다.

준비:
  Windows / AutoCAD 2019 / 사내 승인된 Python / pywin32
  실제 운영 전 원본 DWG를 복제하고 승인된 소스 반입 절차를 준수하세요.
  공유 GitHub에는 실제 품번, 회사 경로, 도면, 진단 로그를 올리지 않습니다.

폴더:
  CAD_PART/
    cadpart_v03.py
    CAD_INPUT/
      도면1.dwg
      도면2.dwg
    CAD_RESULT/ (자동 생성)
  Python이 사용하는 실제 파일명을 cadpart_v03.py로 유지합니다.
  TXT를 실행 가능한 소스로 준비하는 절차는 회사의 정책을 따릅니다.

실행 (cadpart_v03.py 있는 폴더에서):
  python cadpart_v03.py
실도면 없이 가상 시나리오 진단:
  python cadpart_v03.py --demo

결과:
  CAD_RESULT/PARTS_CANDIDATES.csv : 구조 탐색된 품번 후보, 확인 전
  CAD_RESULT/VALIDATION.csv : 오류 코드/사유
  CAD_RESULT/DIAGNOSTICS.csv : 도면별 문자·선·순번 후보 수
  CAD_RESULT/SUMMARY.json : 숫자 요약
  CAD_RESULT/FATAL_ERROR.txt : 치명적 오류가 있을 때만

모바일에 전달할 피드백:
  PowerShell/CMD 마지막 한 줄 그대로
  예: V0.5.1|DWG20|표20|행174|검토3|E00

주의사항:
  1) 현재 E00은 '자동 인식 후보가 있음'이며 완전한 정확도 인증이 아닙니다.
  2) 부품표 구성품이 블록 안에 포함되면 E12 진단 후 별도 구현이 필요합니다.
  3) 표제란/개정표/주기표와 혼재하면 REVIEW 대상으로 검토하세요.
  4) 번호와 수량의 실제 셀 경계는 AutoCAD 선 객체를 기준으로 계산합니다.
  5) G 레이어가 아닌 품목표는 이번 버전에서 인식하지 못합니다.
  6) 폴리라인의 대각선·원호 포함 표 경계는 지원하지 않습니다.
