V0.5.4 신규 진단:
- ANCHOR_RESULTS.csv : '부품목록' 문자 후보의 좌표 (사내 보관)
- DIAGNOSTICS.csv : 도면별 문자수, 후보수, 오류
- STAGES.csv : 도면번호(index)별 START, DOCUMENTS, OPEN, SCAN, MATCH, CLOSE 기록
- VALIDATION.csv : 오류코드
- SUMMARY.json : 결과 집계

실행 환경: Windows / AutoCAD 2019 / 승인된 Python + pywin32
준비: CAD_PART 폴더에 cadpart_v03.py와 CAD_INPUT(시험 DWG 2~3개)
실행: python cadpart_v03.py
짧은 보고 예: V0.5.4|DWG3|문자320|찾음2|성공도면2|실패1|E03

E00: 기준 문자 후보 발견 (실제 부품표인지 검증 전)
E20: 읽힌 문자가 없음
E21: 문자는 있으나 기준 문자 후보 없음
E03: AutoCAD 객체 읽기 실패
E31: COM 호출 재시도 시간초과
E04: 도면 닫기 오류
E99: 치명적 오류
