CAD-PART V0.6.5 | 2026-11-25 | 배포 003

[이번 실제 시험의 기준]
DWG 20개 중 20개 정상 읽기. 실제 구성품 133개.
V0.6.4에서 사용자가 정확한 것으로 확인한 구성품 124개.
누락 9개는 대체로 하나의 병합된 품명 아래쪽에 더 있는
부품번호를 검출하지 못한 사례라고 사용자가 확인함.

[절대 유지하는 부분]
V0.6.3~V0.6.4의 AutoCAD COM 열기/닫기 복구 방식,
'부품목록' 기준점, 헤더 5종 인식, 좌측 T2/T3 연결,
V0.6.4 기존 행 추출 알고리즘은 변경하지 않음.
유일한 기존 데이터 읽기 확장은 원본 TextString을 raw 열로
메모리에 추가 저장하는 것이며 종전 v 값은 그대로 유지.
기존 V0.6.4 행을 제거하거나 억지로 133개를 만들지 않음.

[신규 하단 복원]
1. 각 표의 순번 행에 연결되는 세로 영역을 다시 검사합니다.
2. 병합된 품명의 하단에 존재하는 별도 부품번호 Text 객체,
   또는 MText의 명시적 \P 줄바꿈을 추가로 탐색합니다.
3. 현재 이미 추출된 부품번호와 다르고 명확한 하단 근거가
   있는 경우에만 MERGED_LOWER_RECOVERY 후보로 추가합니다.
4. 후보 수량/도면번호는 같은 수평 높이에서 한 값으로
   분명히 대응할 때만 연결하고, 불명확하면 빈 칸으로 둡니다.
5. 신규 후보는 REVIEW_REQUIRED로 남겨 육안 검증합니다.

[사용 방법]
1. 기존 cadpart_v03.py와 기존 CAD_RESULT 실행 결과를 백업.
2. 사내 승인된 절차로 01_cadpart_v03_전체소스.txt 전체 소스를 준비.
3. 실행 파일명은 기존대로 cadpart_v03.py.
4. CAD_INPUT 폴더에 같은 DWG 20개 복사본 유지.
5. AutoCAD 2019의 다른 작업/팝업 종료 후 한 줄 실행:
python cadpart_v03.py
