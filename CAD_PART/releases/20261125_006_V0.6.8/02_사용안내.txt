CAD-PART V0.6.8 | 2026-11-25 | 배포번호 006

[실제 현장 검증]
DWG 20개 중 20개 읽기 성공 / 부품목록 있는 도면 5개.
실제 구성품 133개.
V0.6.6 후보 136개.
V0.6.7 후보 130개, 선 경계 검토 보류 6개.
사용자가 확인한 결과: 보류된 6개는 모두 실제 부품.
따라서 V0.6.7의 수평선 판정은 6개 모두 잘못 보류한 셈임.

[이번 버전]
1. 기존 AutoCAD COM 안정화와 '부품목록' 및 다섯 헤더 탐색 고정.
2. 좌측 부품표 T2/T3, 병합 품명 하단 복원, V0.6.6의 확정 중복 필터 유지.
3. V0.6.7에서 추가한 LINE 수집과 M51/M52/M53 판단은 참고 자료로만 유지.
4. 수평선이나 인접 행의 거리 때문에 부품을 최종 CSV에서 제외하지 않음.
5. 예상 기준: 같은 20 DWG 실행 시 기존 V0.6.6의 136개 복원.
6. 실제 133개를 출력 개수에 강제로 맞추지 않음.
7. 다음 개선은 품명 병합 범위+부품번호별 정렬/셀 경계 확인 후 진행.

[준비 및 실행]
- 기존 cadpart_v03.py 와 이전 결과 폴더를 백업.
- GitHub 01_cadpart_v03_전체소스.txt 전체 소스를 사내 승인 절차에 따라 준비.
- 실행 파일명 cadpart_v03.py 유지.
- 기존 CAD_INPUT DWG 20개 그대로 두기.
- AutoCAD 2019 다른 명령과 팝업이 없는 상태로 실행:
python cadpart_v03.py

[출력]
CAD_RESULT/RUNS/최신실행번호/
- BOM_ROWS_CANDIDATES.csv : 선 경계 필터로 제외하지 않은 최종 후보
- BOM_ROWS_PRELINE_V066.csv : V0.6.6의 선 경계 적용 전 후보 (비교 기준)
- BOM_ROWS_RAW_V065.csv : V0.6.5 144개 원시 후보
- LINE_ADVISORY_ONLY.csv : M51/M52/M53 선 경계 검사 경고 (최종 목록에서도 유지됨)
- LOWER_LINE_REVIEW.csv : 이전 형식과 호환되는 선 경계 경고
- LOWER_RECOVERY_FILTERED.csv : V0.6.6 확정 중복 필터 후보
- SUMMARY.json : geometry_advisory_only=true / geometry_excluded_rows=0
