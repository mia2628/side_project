CAD-PART V0.5.7 / 2026-11-24 / 배포 005
목적: V0.5.6 코드 버그 수정과 오류 원인 분리.

핵심 수정
1. complete 변수가 정의되기 전에 사용된 오류 제거.
2. AutoCAD 도면 읽기와 Python 기준문자/헤더 분석 오류 구분.
3. 문자 수와 기준점 수가 분석 단계 오류 때문에 0으로 덮이지 않도록 개선.
4. HEADER_RESULTS.csv 및 HEADER_CANDIDATES.csv 생성 유지.
5. 한 품목이 여러 DWG를 가질 수 있으므로 DWG 개수와 고유 품목 수는 구분.
6. 임의의 최상위 조립품 지정 없음.

실행 환경
Windows, AutoCAD 2019, 사내 승인된 Python + pywin32.
CAD_PART\cadpart_v03.py
CAD_PART\CAD_INPUT\ (2~3 DWG부터 시험)
CAD_PART\CAD_RESULT\ (결과 자동 생성)

명령 한 줄: python cadpart_v03.py
별도 가상 테스트: python cadpart_v03.py --demo

SUMMARY.json / HEADER_RESULTS.csv / HEADER_CANDIDATES.csv
ANCHOR_RESULTS.csv / DRAWING_INDEX.csv / DIAGNOSTICS.csv
VALIDATION.csv / STAGES.csv

중요
이번 버전은 코드 오류 수정본이며 실제 DWG 환경에서의 정확도는 검증되지 않았습니다.
