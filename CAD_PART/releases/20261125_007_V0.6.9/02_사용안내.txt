CAD-PART V0.6.9 / 2026-11-25 / 배포 007
[중요 정정] 이 릴리스는 V0.6.5가 아니라 V0.6.6의 전체 코드를 기반으로 합니다.

현장 확인: 총 실제 133개 / V0.6.6 결과 136개 / V0.6.7 선경계 보류 6개가 모두 실제 부품.
따라서 V0.6.7/V0.6.8 선 경계 필터는 적용하지 않았습니다.

절대 유지:
- CAD 파일명 cadpart_v03.py 및 python cadpart_v03.py 명령
- V0.6.6에서 성공했던 AutoCAD 20/20 읽기, 부품목록 제목 및 5개 헤더 고정
- 좌측 부품표, 병합 품명 하단, V0.6.6 확정 중복 필터
- BOM_ROWS_CANDIDATES.csv에는 V0.6.6의 결과를 수정하지 않고 기록. 동일한 DWG에서는 136개 예상

신규 실험 출력(기존 결과와 분리):
- BOM_ROWS_PRECISION_EXPERIMENT.csv : 같은 순번 안 부품번호가 정확히 중복되면 1개만 남기는 실험 목록
- PRECISION_DEDUP_REMOVED.csv : 실험 과정에서 중복으로 분류한 항목
- PRECISION_REVIEW.csv : 다른 순번에 더 가까운 위치, 수량/도면번호 불분명 등 경고만 기록
기존 최종 목록에서 항목을 삭제하거나 수량 133을 강제로 맞추지 않습니다.

실행:
1. 승인된 방식으로 GitHub의 01_cadpart_v03_전체소스.txt를 준비
2. 기존 cadpart_v03.py 백업
3. 동일한 CAD_INPUT 20개 DWG 복사본과 AutoCAD 2019 사용
4. python cadpart_v03.py

결과 위치: CAD_RESULT/RUNS/최신실행번호/
다음 피드백:
- 최종 실행 한 줄
- BOM_ROWS_CANDIDATES.csv 행 수 (V0.6.6 기준: 136 기대)
- BOM_ROWS_PRECISION_EXPERIMENT.csv 행 수
- PRECISION_DEDUP_REMOVED.csv 행 수
- PRECISION_REVIEW.csv 행 수
- 실제 부품이 실험에서 잘못 빠진 건수(있다면)

V0.6.9는 현장 실도면 실행 전 시험판입니다. 정확히 개선되지 않았다면 V0.6.6 그대로 사용하세요.
