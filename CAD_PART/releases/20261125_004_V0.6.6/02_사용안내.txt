CAD-PART V0.6.6 | 2026-11-25 | 배포순번 004

[검증된 기준]
사용자 실도면 DWG 20개 읽기 성공, 부품목록 있는 도면 5개.
실제 구성품 총 133개.
V0.6.4 정상 추출 124개.
V0.6.5 전체 후보 144개 (추가 하단 후보 21개), 사용자가 확인한 실제 누락 0개.
V0.6.5 일부 추가 후보가 인접한 다른 행의 부품번호를 다시 가져와 과잉 생성.

[이번 패치 범위]
V0.6.3 COM 읽기 안정화, V0.6.4 부품목록 기준점/헤더/좌측 추가표 인식,
V0.6.5 병합 품명 하단 복원 알고리즘을 변경하지 않습니다.
해당 결과 생성 후 오직 source_kind=MERGED_LOWER_RECOVERY만 별도 후처리합니다.

M41: 이미 같은 표 같은 순번의 기존 품목으로 존재하는 부품번호는 제외.
M42: 인접 순번의 기존 부품번호가 동일하고 실제 위치도 겹치는 경우만 제외.
M43: 동일 순번에서 같은 부품번호를 두 번 복원한 경우 제외.
M44: 부품번호는 다르지만 인접 순번과 좌표가 너무 가까운 경우,
     잘못된 행 소속일 수 있어 검토 파일로 보류합니다.
중복/보류 후보는 삭제되지 않고 별도 CSV에 저장합니다.

[실행]
1. 기존 cadpart_v03.py와 기존 CAD_RESULT 보관.
2. GitHub에서 01_cadpart_v03_전체소스.txt 확보.
3. 승인된 사내 반입 및 실행 절차로 cadpart_v03.py 준비.
4. CAD_INPUT에 같은 DWG 20개를 넣고 AutoCAD 2019 실행.
5. 실행 명령은 한 줄 그대로:
python cadpart_v03.py

[파일]
CAD_RESULT/RUNS/최신실행번호/
BOM_ROWS_BASELINE_V064.csv : 기존 정확하게 검토한 124개 기준 결과
BOM_ROWS_RAW_V065.csv      : V0.6.5 방식 필터 전 전체 후보 (참고: 144개)
BOM_ROWS_CANDIDATES.csv   : V0.6.6에서 중복 및 소속 불분명 후보를 보류한 목록
LOWER_RECOVERY_FILTERED.csv : M41/M42/M43 중복으로 분류된 후보
LOWER_RECOVERY_REVIEW.csv : M44 소속 불분명하여 보류한 후보
LOWER_RECOVERY_AUDIT.csv  : 기존 하단 추출 로그 + V0.6.6 분류 로그
SUMMARY.json              : raw_v065_candidates, part_row_candidates,
                            filtered_duplicate_recoveries, uncertain_recoveries

[결과 피드백]
1. 마지막 화면 출력 한 줄 (DWG/읽음/목록도면/행/검토/상태)
2. RAW_V065 데이터행 수
3. CANDIDATES 데이터행 수
