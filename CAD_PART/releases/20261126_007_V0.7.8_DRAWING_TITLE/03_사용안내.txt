CAD-PART V0.7.8 | 2026-11-26 | 배포번호 007

[실도면 피드백 반영]
- V0.7.7의 도면 자체 품명 추출은 정상: 품명 탐색 좌표 변경 없음
- 기존 부품목록 '부품목록' 앵커 좌표 (x,y) 기준:
  도면 자체 품명 = (x+30, y-30) [유지]
  도면 자체 품번 = (x+60, y-45) [기존 x+30에서 X +30]
- 두 추출 위치 모두 같은 도면 공간(Model/Layout)에서 문자 삽입점을 기준으로 탐색
- 탐색 허용범위 X ±12, Y ±7 (도면 좌표 단위): 기존과 동일

[그대로 유지]
- V0.6.6 기반 부품목록, 5개 헤더, 좌측 다중표, 병합 하단 부품 추출
- V0.7.2 기반 직속 부모-자식 연결 및 파일명 검토 후보
- V0.7.6 기반 계층형 엑셀의 Level별 음영색
- V0.7.7의 도면 시작 행에 실제 품명/품번 표시
- 원본 DWG 읽기 전용, 저장하지 않음
- 최상위 조립체/Level을 임의로 확정하지 않음

[처리속도 소폭 개선]
- DWG 열기 직후 고정대기: 0.75초 -> 0.70초
- DWG 닫기 직후 고정대기: 0.55초 -> 0.50초
- 74개 도면에서 이론상 고정대기 7.4초 감소 (실제 전체 처리시간과 다를 수 있음)
- 기존 COM 재시도와 통신 안정화 처리 변경 없음
- 재실행 시 SUMMARY.json의 elapsed_seconds를 이전과 비교

[사내 실행]
1. 기존 두 Python 실행 파일과 CAD_RESULT/RUNS의 과거 결과 백업
2. 회사가 승인한 반입·실행 절차로 새 TXT 전체 소스 준비
3. 기존 CAD_INPUT에 DWG 74개 또는 새 시험 도면 배치
4. AutoCAD 2019 실행 후 다른 작업/팝업 종료
5. 부품목록 및 도면 자체 품명/품번 추출:
python cadpart_v03.py
6. 최신 RUNS 폴더의 DRAWING_TITLE_RESULTS.csv에서 drawing_part_number 확인
7. 계층형 엑셀 생성:
python cadpart_hierarchy_v01.py
