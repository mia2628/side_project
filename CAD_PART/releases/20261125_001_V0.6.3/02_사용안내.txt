CAD-PART V0.6.3 | 2026-11-25 | 배포 001

사용자 검증 기준:
V0.6.2|DWG20|읽음6|목록도면2|목록없음4|행60|검토4|SCAN바쁨1|E31
VALIDATION 오류: E33 13건 / E31 1건 / E04 1건.
부품표에서 추출된 후보는 현행 알고리즘 중 가장 정확한 편이라는 사용자 피드백.

이번 릴리스에서 변경한 부분:
- 구성품의 문자/헤더/1-2-3... 행 복원 알고리즘은 유지.
- AutoCAD Documents.Open 접근 실패(E33) 때 동적 COM 바인딩으로 재접근.
- 한 번 실패하면 실행 중 AutoCAD 객체를 다시 얻어 최대 총 3회 시도.
- 이전에 열려 있는 동일 파일을 발견하면 다시 열지 않고 그 문서를 재사용.
- 도면을 닫을 때 이번 프로그램이 연 도면에만 Close(False) 호출.
- 닫기 실패 후 다음 도면을 위해 COM 연결 재확인.
- 기존 SCAN E31 재시도 정책 유지.

주의:
기존의 E33은 Open 메서드 접근 오류였고, 위의 재연결은 원인 가설에 기초한 개선입니다.
이 버전은 실제 AutoCAD 2019 실행 전 시험판이며 완전 해결을 보장하지 않습니다.
여러 파일을 일괄로 실행하기 전에 2~3개 먼저 검사하세요.
AutoCAD에서 실행 중인 명령 및 팝업을 종료한 상태에서 시험하세요.

사용방법:
1. GitHub 01_cadpart_v03_전체소스.txt를 받습니다.
2. 회사에서 승인된 코드 반입·실행 절차를 따릅니다.
3. 기존 cadpart_v03.py는 별도 백업하고 새 버전으로 준비합니다.
4. CAD_INPUT 폴더에 DWG 복사본을 넣습니다.
5. 한 줄 실행: python cadpart_v03.py
