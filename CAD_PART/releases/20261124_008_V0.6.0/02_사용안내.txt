CAD-PART V0.6.0 | 2026-11-24 | 배포순번 008

목표:
V0.5.9에서 성공한 부품목록 기준점 + 5개 헤더 인식을 유지하고,
헤더 위 1번 구성품을 시작으로 위쪽 2,3,4... 연속 품목을 추출합니다.
실제 정답 BOM이 아닌 검토용 후보입니다.

추출 열:
부품목록 순번(item_no) / 품명(part_name) / 수량(qpa) /
부품번호(part_number) / 도면번호(drawing_number).
위쪽 주기/수정이력과 혼동하지 않도록 순번이 단절되면 자동으로
그 이상의 데이터를 부품으로 확정하지 않습니다.
순번 중단/누락과 빈 셀은 별도 검토합니다.

알려진 제한:
- 이번 버전은 우측 첫 부품표의 연속된 구성품 행을 우선 복원합니다.
- 왼쪽 추가 부품표 이어붙이기는 다음 단계에서 검증합니다.
- 열 위치는 헤더 문자 좌표에서 추정한 '후보'이므로 셀 폭,
  병합셀/다행 문자에 따라 수량·부품번호가 잘못 배치될 수 있습니다.
- 품목 간 상하위 관계 자동 확정 기능은 이번 버전에 포함하지 않았습니다.
- XREF/Proxy 등 일부 형식은 미지원입니다.

속도:
AutoCAD 도면 열기/닫기 고정 대기 시간을 1.5s/0.5s에서
0.4s/0.15s로 조정했습니다. COM 바쁨 호출 재시도는 유지합니다.
실제 전체 실행시간은 SUMMARY.json의 elapsed_seconds에 기록합니다.
속도 향상은 반드시 사내 실도면에서 비교 검증해야 합니다.

실행:
승인된 절차로 01_cadpart_v03_전체소스.txt 전체 소스를 준비합니다.
기존 실행 파일명 cadpart_v03.py는 유지합니다.
CAD_INPUT 폴더에 DWG 2~3개를 먼저 넣으세요.
AutoCAD 2019가 열려 있고 명령/팝업이 없는 상태에서
python cadpart_v03.py
가상 테스트: python cadpart_v03.py --demo

출력은 매번 새 폴더에 저장됩니다.
CAD_RESULT/RUNS/실행번호/BOM_ROWS_CANDIDATES.csv  ← 구성품 후보
CAD_RESULT/RUNS/실행번호/ROW_VALIDATION.csv        ← 누락/불완전
CAD_RESULT/RUNS/실행번호/HEADER_RESULTS.csv
CAD_RESULT/RUNS/실행번호/VALIDATION.csv
CAD_RESULT/RUNS/실행번호/SUMMARY.json             ← 처리시간 포함

모바일 피드백 한 줄 예:
V0.6.0|DWG3|읽음3|헤더3|행18|검토2|오류0|E52
(숫자는 예시)

E00: 자동 후보 생성 및 기존 검사 경고 없음 (정확도 검증 의미 아님)
E51: 헤더 위 1번 행 또는 후보를 찾지 못함
E52: 셀 구성 미완성/수량 의심 등 행 검토 필요
E53: 순번 단절 (ROW_VALIDATION.csv에서 확인)
E54: 순번 거리/행 간격 이상
E40: 헤더 5개 미인식
E41: Python 행/헤더 분석 예외
E03/E31: AutoCAD 읽기/COM 통신 문제
E35: 소스 버전 무결성 검사 실패
E99: 치명적 오류
